## 新增 ADR 规则

1. 文件名：`ADR-<编号>-<短横线主题>.md`
2. 必填字段：状态、日期、背景、决策、理由、后果
3. 状态取值：`提议中`、`已接受`、`已取代`、`已废弃`
4. 被取代的 ADR 不删除，只改状态并指向新 ADR
